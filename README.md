# Unitree G1 → FF Master Retargeter

Interactive web viewer comparing Unitree G1 source motion with FF Master retargeted animation.

- **Live demo:** https://zhiyangrobot.github.io/g1-ffmaster-retarget/
- **Dataset (FF Master CSV + bake):** https://huggingface.co/datasets/zhiyangrobot/g1-ffmaster-retarget
- **Original data:** https://chingmudata.github.io/MotionDecode/
- **Unitree G1 CSV:** https://huggingface.co/datasets/CMRobot/MotionDecode
- **Retarget tool:** https://github.com/NVIDIA/soma-retargeter

Maintainer: [@zhiyangrobot](https://github.com/zhiyangrobot)
