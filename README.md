# Unitree G1 → FF Master Retargeter

Interactive web viewer comparing Unitree G1 source motion with FF Master retargeted animation.

- **Unitree G1 source CSV:** https://huggingface.co/datasets/CMRobot/MotionDecode
- **Original showcase:** https://chingmudata.github.io/MotionDecode/
