# Unitree G1 → FF Master Retargeter

Interactive web viewer comparing Unitree G1 source motion with FF Master retargeted animation.

- **Live demo (GitHub Pages):** https://zhiyangrobot.github.io/g1-ffmaster-retarget/
- **Motion bake / meshes:** https://huggingface.co/datasets/zhiyangrobot/g1-ffmaster-retarget
- **Original data:** https://chingmudata.github.io/MotionDecode/
- **G1 CSV:** https://huggingface.co/datasets/CMRobot/MotionDecode
- **Retarget tool:** https://github.com/NVIDIA/soma-retargeter

Clip JSON and GLB models are loaded from Hugging Face via `manifest.baseUrl`. This repo only hosts the viewer shell and playlist manifest.
